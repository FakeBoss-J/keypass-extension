# KeyPass 网页密码助手

本地轻量密码管理器的 Chrome / Edge 浏览器插件。用于登记网站链接、网站名、账号、密码和账号名称。数据保存在本机加密存储中，不上传网络。

## 安装

1. 克隆或下载本仓库。
2. 打开 Chrome 或 Edge，在地址栏输入 `chrome://extensions` 并回车。
3. 打开右上角的「开发者模式」。
4. 点击「加载已解包的扩展程序」，选择本仓库根目录（包含 `manifest.json` 的目录）。
5. 在浏览器工具栏找到 KeyPass 图标并固定到工具栏。

## 使用

- 首次使用设置至少 8 位主密码。
- 打开任意网页后，点击工具栏中的 KeyPass 图标。插件会按当前域名匹配账号，点击「一键填入」即可填入用户名和密码。
- 网页的账号输入框和密码输入框右侧会出现钥匙图标。点击即可填入；若该网站保存了多个账号，会弹出浮层供选择。
- 点击弹窗右上角「管理中心」可新增网站、编辑账号、随机生成强密码、修改主密码，以及导入或导出 `.kps` 密文备份。
- 连续 30 分钟无操作会自动锁定，并清除内存中的明文数据。

## 说明

插件可以独立使用，不需要同时运行桌面端。请不要把主密码、明文密码或个人备份文件提交到本仓库。
